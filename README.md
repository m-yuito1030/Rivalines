# Rivalines

Webブラウザで遊べる、交通・街づくりのシミュレーション(サンドボックス・マルチプレイ)。要件は [docs/REQUIREMENTS.md](docs/REQUIREMENTS.md)。

## 開発
開発の流れ(ブランチ・PR・リリース)は [docs/WORKFLOW.md](docs/WORKFLOW.md)、コードの構成は [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)。出す前に `npm run check`(型・整形・テスト)。

```bash
npm install
npm run dev        # http://<host>:5173 (LANからも可)
npm run typecheck
npm test
```

操作: 右/中ドラッグ・WASD で移動、ホイール/Q・E でズーム、Shift で高速、ミニマップクリックでジャンプ。
建設(左ドラッグで直線): R=道路 / O=一方通行(ドラッグ方向に通行) / T=双方向化 / X=撤去 / B=停留所 / V・Esc=移動。路線は右パネルの「＋ 路線作成」から停留所を順にクリックして Enter で確定し、「＋バス」で車両を追加。Space で一時停止。

街の成長間隔は `src/shared/world/towns.ts` の `GROWTH_BASE_TICKS` で調整(1tick = 実0.1秒 @x1)。

## サーバーを動かして遊ぶ(マルチプレイ)
世界を進めるサーバー(Node)と、画面を配るサーバー(nginx)を、Docker でまとめて起動します。

```bash
git clone https://github.com/m-yuito1030/rivalines.git && cd rivalines
echo 'INVITE_CODE=好きな文字列' > .env      # 招待コード。公開するときは必ず設定する(新規登録に必要になる)
docker compose up -d --build
```
`http://<サーバーのアドレス>:8092` で遊べます。更新するときは、`git pull` のあと同じ `docker compose up -d --build`(世界のデータは残ります)。

- **設定**(`docker-compose.yml` の `environment`): `WORLD_SIZE`(世界の一辺。既定 65535)・`MAX_ONLINE`(同時に接続できる人数。既定 100。登録できる人数に上限はありません)・`REGISTER_PER_HOUR`(1時間に新規登録できる人数。既定 300)・`INVITE_CODE`(空なら、新規登録は誰でもできる)。
- **データ**: 世界(`world.sav`)・アカウント(`accounts.json`)・ログインの署名鍵(`token.secret`)は、Docker のボリューム `multi-data` の `/data` に保存されます。**バックアップを取ってください**(1つのファイルだけです)。
- **公開するとき**: 暗号化なしの HTTP だと、パスワードが通信の途中で読めます。HTTPS の入口(リバースプロキシ)の後ろに置いてください。前段にプロキシがある場合は、利用者の IP アドレスを `X-Real-IP` で nginx に渡さないと、全員が1つの接続元として制限されます。
- **開発中**: サーバーは `npm run server`(8091)、画面は `npm run dev`(5173。`/api` と `/ws` を 8091 に中継)。

### 画面だけの試し見(サーバーなし)
サーバーが無いので、ログインも、マルチプレイも、できません。見た目の確認用です。
```bash
npm run build
npm run preview    # http://<server-ip>:4173 に静的配信
```
Ubuntu のサーバーで、Node.js の導入から起動までまとめて行うスクリプトもあります(`bash scripts/deploy.sh`。`stop|status|logs` で停止/状態/ログ。ポートは `PORT=8080 bash scripts/deploy.sh`)。

### 操作
| キー | 動作 |
|---|---|
| R / O / T / X | 道路 / 一方通行(ドラッグ方向) / 双方向化 / 撤去 |
| Y / H | 道路の橋・トンネル / 線路の橋・トンネル |
| B / L / K / P | バス停 / 線路 / 駅 / 空港 |
| U / J / G | 地面を上げる / 下げる / 整地(ドラッグで範囲) |
| V・Esc | 移動 |
| Enter | 路線作成の確定 |
| Space / Ctrl+S | 一時停止 / セーブ・ロード |

路線は右パネルの ＋🚌 ＋🚆 ＋✈ から作成し、停留所を順にクリックして Enter。「＋車両」で追加します(車種は路線ごとに選択)。

### スマホで遊ぶ
同じLANから `http://<サーバIP>:4173`(または dev の 5173)を開く。ホーム画面に追加すると全画面で起動(HTTPS配信ならPWAとしてインストール可)。
スマホではマップサイズ512を既定にしています(1024以上は端末のメモリ次第)。下のツールバーは横スクロールできます。

### 既知の制約・今後
- 乗り換えは「同じ停留所を共有する路線」間のみ(徒歩での乗り換えなし)
- 鉄道の信号は未実装(経路全体を予約する簡易閉塞)。編成の分割・併合も未実装(併結済みの編成として定義)
- 地形整備(整地)なし。段差をまたぐ道路・線路は不可
- 航空機は直線飛行のみ(滑走路の向き・混雑なし)
- 資金・コストなし(サンドボックス)
