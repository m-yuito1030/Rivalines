# コンピューターが運営する会社(AI 会社)

人が少ないときも、世界に「ほかの会社が動いている感じ」を出すための仕組み。AI といっても、モデルは使わず、決まった手順(ルール)で動く(`server/ai.ts`)。

## 会社の種類(専門)と性格
会社ごとに、専門と性格が決まっている(`src/shared/sim/economy/aiCompanies.ts`)。メニューのプレイヤー一覧に、「バス専門・積極的」のように出る。

| 専門 | やること |
|---|---|
| バス専門 | 街と街を道路でつなぎ、バス停・車両基地・路線・バスを作る |
| 鉄道専門 | 街の近くに駅を置き、駅と駅を線路でつなぎ、車両基地・路線・列車(1路線に1本)を作る |
| 不動産・施設 | 大きな街にホテル・公園・百貨店・モールを建てる。売り出し中の物件を、評価額で買う。持っている施設を改良する |
| 総合 | バス → 不動産 → 鉄道 → 不動産 の順に、交代でやる |

| 性格 | 動き方 |
|---|---|
| 積極的 | 動きが速い(慎重の約2.7倍)。手元の資金を少なく(300万円)しか残さず、足りなければ借りる(最大2500万円)。長い路線(320タイルまで)を、多く(12路線まで)。バスは1台多く。施設は14まで |
| 慎重 | 動きがゆっくり。資金を1200万円は残し、借りない。近い街(220タイルまで)だけ、少なく(5路線まで)。施設は6まで |

最初の4社は、種類がひととおり揃う(バス・鉄道・不動産・総合)ように並べてある。

## 動き方(バス・鉄道)
1. 自分の「ホームの街」(人口の多い上位10の街から、会社ごとに決まる)から、近い街を選ぶ(どこにも届かないホームは、次の街に替える)
2. 道路(鉄道なら、駅と線路)を、地形(水・建物・坂)を避けて、1回に12タイルずつ伸ばす。道が少しずつ伸びていくのが見える
3. 停留所(鉄道は駅)・車両基地・路線・車両を作る
4. 一休みして、次の街へ広げる

プレイヤーと同じ命令(`server/commands/`)を使うので、費用・持ち主・決まりは同じ。お金が足りないときは、足りるまで待つ。つなげない組み合わせは、あきらめて別の街にする。鉄道は単線なので、1路線に列車は1本(2本だと、向かい合って止まるため)。

## 画面での扱い
- 会社の一覧・ランキングに、色と名前つきで並ぶ。メニューでは「(コンピューターが運営)」と専門・性格が出て、送金・通報・全駅の許可はできない。
- 政府(国策と課税)の「大企業・小さい会社」の分け方には、AI 会社を数えない(プレイヤーだけ)。

## 設定
- 環境変数 `AI_COMPANIES`(0〜12。既定 0 = いない)。次期バージョンの構成(`docker-compose*.yml`)は 4。本稼働は、設定しなければ 0。
- AI 会社の会社番号は、60001 から。アカウントの番号が、その手前(60000)に届くと、新規登録を止める(タイルの持ち主の記録が16ビットのため)。
- 世界は、誰かがログインしている間だけ進む。AI 会社も同じで、誰もいなければ止まっている。

## 調整する場所
- 性格の数字(動きの速さ・資金・借入・距離・路線の数・施設の数): `server/ai.ts` の `STYLES`
- 動く間隔・1回に伸ばす長さ: `AI_STEP_TICKS`・`EDGES_PER_STEP`
- 会社の名前・色・専門・性格: `aiCompanies.ts` の `PROFILES`

## 保存
AI の「いまの工事」の状態は、保存しない(再起動のあとは、新しい計画から始める。すでにある道・線路・停留所・施設は使い回す)。会社のお金・路線・車両・施設は、ふつうの会社と同じように保存される。

## まだないこと
航空、AI どうしの提携や買収、広告や料金の調整、倒産。
