# 運営(問題のあるプレイヤーへの対応)

運営の操作は、**公開されない経路**だけで行う。外のインターネットからは届かない(nginx が `/api/admin` を通さない)。サーバーのコンテナの中から、`ADMIN_KEY` を使う。

## 準備
`.env` に `ADMIN_KEY=長いランダムな文字列` を書いて、`docker compose up -d`。`ADMIN_KEY` が空なら、運営用の API は無効。

## 操作
`docker compose exec server npx tsx server/admin.ts <操作> [名前|#ID] [理由]`

| 操作 | 内容 |
|---|---|
| `reports` | 届いている通報の一覧(ID・通報した人・された人・理由・時刻) |
| `dismiss <通報ID>` | その通報を、対応済みにして消す |
| `players` | 接続中のプレイヤー |
| `traffic` | 通信量(サーバーが外へ送った量)。起動してからの合計と、直近1時間ごとの区切り。1人あたりの量・メッセージの種類ごとの割合・圧縮した場合の見積もり・同時10/30/100人が1か月つながったときの量(GB)が出る |
| `chat` | 直近のチャットの発言(メモリ上の100件。再起動で消える) |
| `mute <名前> [分]` | その人のチャットを止める(既定60分。0 で解除。再起動で解ける)。BAN するほどでないときに |
| `announce <タイトル> <本文>` | お知らせを出す(メニューに出る。タイトルは1つの語か、引用符で囲む)。本稼働に出すと、次期バージョンにも見える |
| `announcements` / `unannounce <番号>` | お知らせの一覧 / 消す |
| `kick <名前>` | 接続を切る(また入り直せる) |
| `ban <名前> [理由]` | 利用停止。切断され、ログインできなくなる(理由は本人に表示)。その人への通報は消える |
| `unban <名前>` | 利用停止を解除 |
| `clear <名前>` | 不適切な会社名・プロフィールを消す(会社名はアカウント名に戻る) |
| `resetpw <名前>` | 一時パスワードを発行(これまでのログインは無効)。本人に別の経路で伝える。入ったら本人が変更する |
| `delete <名前>` | アカウントと会社を削除(施設は売り出し物件に、路線・車両・停留所・車庫は撤去) |

名前の代わりに `#12`(アカウントID)でも指定できる。

## 通信量の見方
クラウドの通信料やサーバーの選び方、通信の圧縮を入れるかを、実測で決めるための計測。数えるのは**合計と、メッセージの種類ごとの大きさだけ**で、だれが送ったか・どこから来たか、は持たない(個人情報は取らない。[プライバシーポリシー](../public/privacy.html)と同じ方針)。
- `docker compose exec server npx tsx server/admin.ts traffic` で、いまの値を見られる。
- 1時間ごとに、サーバーのログに `[traffic] ...` の1行が出て、`traffic.jsonl`(データの置き場)に1行の JSON が追記される(人がいなかった時間は出ない)。
- 大きさは、圧縮しないときに回線を流れる量。「圧縮すると約◯%」は、一部のメッセージを試しに圧縮した見積もり(WebSocket の圧縮を入れたときの目安)。
- 月の見積もり(10/30/100人)は、「その人数が24時間×30日つなぎっぱなし」の場合。実際は、つながっている時間がもっと短いので、**上限の目安**として見る。
- 測るときは、**人が実際に遊んでいる時間帯**の値を見る(人がいないときは、種類ごとの割合が実際と違う)。

## プレイヤー側の機能
- **通報**: メニューのプレイヤー一覧の「通報」から、理由(200文字まで)を送る。1日5件まで・同じ相手には1日1回。
- **全体チャット**: メニューの「💬 チャット」。発言は100文字まで、10秒に5件まで。発言の「通報」「非表示」ができる(通報には、その発言の文章が添えられる)。記録はメモリの中だけ。
- **お知らせ**: メニューを開くと一番上に出る。新しいものがあれば、メニューに赤い点が付く。
- **パスワード変更・退会**: メニューの「パスワードの変更・退会」から。現在のパスワードが必要。退会すると、`delete` と同じく会社が消える。

## 方針(個人情報)
メール・本名・IP は保存しない。複数アカウントの禁止は、規約と通報・BAN で守る。通報には、ID・名前・理由・時刻だけを保存する(最大500件、古いものから消える)。

## 通報がきたら
1. `reports` で内容を見る。2. 必要なら `clear`(文章)/ `kick` / `ban`。3. `dismiss` で片づける。
