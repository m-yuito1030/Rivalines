# 政府(国策と課税)

先に始めた人が、そのまま有利でいつづけないようにするための仕組み。マルチプレイの世界だけにある。数字の調整は `src/shared/sim/economy/government.ts` の定数で行う。

## 国策(毎月)
その月の国策は、世界の種(seed)と年月だけで決まる(全員が同じで、サーバーを再起動しても変わらない)。来月の国策は、画面の右上の「政府」から先に見られる。

| 国策 | 内容 |
|---|---|
| 通常の運営 | 何もない |
| 増税 | 大企業への課税が2倍。法人税が大企業だけ +5 ポイント |
| 減税 | 大企業への課税が半分。法人税が全社 -5 ポイント |
| 公共事業 | 建設費が2割安い |
| 観光振興 | 施設の来場者が2割増える |
| 環境規制 | 車両の運行費が増える(車両が多い会社ほど重い。最大 +25%) |
| 規制緩和 | 車両の運行費が1割安い |

## 政権(毎年度)
年度(4月始まり)ごとに、政権の性格が決まる。大企業への課税の強さが変わる。

- 企業寄り: 課税 0.6 倍・法人税の上乗せ 0.5 倍
- 中道: 1 倍
- 再分配重視: 課税 1.5 倍・法人税の上乗せ 1.5 倍

## 大企業への課税と還元
- オンラインの会社を、純資産で並べる。上位3分の1が「大企業」、下位の半分が「小さい会社」(3社未満のときは、課税も還元もしない)。
- 月末に、大企業が純資産の 0.3%(国策・政権で増減)を納める。集めたお金は国庫に入り、小さい会社に等分して配られる(1社あたりの上限あり。配りきれない分は国庫に残る)。
- 決算の法人税も、大企業は +5 ポイント(政権で増減)。
- オフラインの会社は、他のことと同じく止まっていて、課税も還元も受けない。

## 仕組み
国策と政権は日付から計算するので、保存するのは国庫の金額だけ(セーブの `gov`)。会社には、毎日の締めで建設費・運行費の倍率と法人税率を設定する。
