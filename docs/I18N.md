# 多言語対応(日本語・英語・ドイツ語・フランス語)

## 言語の決まり方
1. 本人が選んだ言語(ログイン画面とメニューの「言語」欄。ブラウザに保存される)。`?lang=en` を付けて開いても指定できる
2. ブラウザの言語設定(`navigator.languages`)の上から順に、対応している最初のもの
3. どれにも当てはまらなければ英語

画面の言語は、ゲーム中でも切り替えられる(すぐに差し替わる)。

## クラス(`src/shared/i18n/`)
```
Locale  ── 文の取り出し・{名前} の差し込み・数/金額/日付の書き方(土台)
  └ Ja  ── 日本語。すべての文を持つ基準
      └ En ── 英語。訳した文だけ持ち、足りない文は日本語(継承元)で補う
          ├ De ── ドイツ語(`de/*.ts`)。足りない文は英語 → 日本語で補う
          └ Fr ── フランス語(`fr/*.ts`)。同上
```
- 英語に訳していない文は、日本語のまま出る(画面が壊れない)。
- ドイツ語・フランス語のカタログは、英語(`en/*.ts`)と同じキーで、同じファイル分け(ui / rules / client / server / panels / social / government)。施設・駅のデザイン名(`en/names.ts`)だけは、まだ英語のまま出る。利用規約・プライバシーポリシー・マニュアルも英語版を開く
- 英語に文を足したら、ドイツ語・フランス語にも足す(`server/i18n.test.ts` が、訳し忘れと {名前} の食い違いを見つける)
- 新しい言語を足すには、`Ja`(または `En`)を継承したクラスを作り、カタログ(`xx/*.ts`)と `date` `compactMoney` などの書き方を書き、`index.ts` の `LOCALES` に足す。

## 文の呼び方
| | 使いどころ | キー |
|---|---|---|
| `t('ui.go')` | 画面(index.html)の固定の文。HTML には `data-i18n` `data-i18n-title` `data-i18n-placeholder` を付ける | 意味のあるキー(`ja/ui.ts` が日本語、`en/ui.ts` が英語) |
| `tr('日本語の文 {n}', { n })` | プログラムの中の文・名前(メッセージ、施設・車種・イベントの名前、デザイン名) | 日本語の文そのもの。英語は `en/*.ts` に `'ja:日本語の文'` で置く |

- `{名前}` は差し込みの場所。英語の文にも同じ名前を書く。
- 個数で文が変わる場合は `tn('キー', n)`(`キー.one` / `キー.other`)。
- 日本語の文を直したら、英語のカタログのキー(`ja:` の後ろ)も同じに直す。直し忘れは、`server/i18n.test.ts` が見つける。

## テスト(`server/i18n.test.ts`)
- 言語の決め方(本人の選択 → ブラウザ → 英語)
- `Ja` / `En` の継承と、足りない文の補い方
- index.html の `data-i18n` のキーが、日本語にも英語にもあること
- `tr('…')` の日本語の文が、すべて英訳されていること
- 施設・駅のデザイン名が、すべて英訳されていること

## 訳の進み具合
- 済み: 画面の固定の文(index.html)、各パネル(路線・情報・経営・一覧・ランキング・競り・売り出し・分析・ダイヤ)、ログイン・接続・メニュー・画面上部の表示、建設パネル、施設・駅のデザイン名、天気・イベント・評価・街の規模の名前、サーバーの操作結果メッセージ(接続時に `?lang=` で言語を伝え、サーバーがその言語で返す)
- これから: 建設できない理由など共有コードの文の一部(未訳は日本語のまま)、利用規約・プライバシーポリシー
