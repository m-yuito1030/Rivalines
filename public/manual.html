1. Rivalines とは

Rivalines は、ブラウザで遊べるマルチプレイの交通・街づくりゲームです。あなたは交通会社の社長になり、道路や線路を敷いて、バス・電車・飛行機の路線を開きます。駅やバス停の近くに乗客が集まり、街が育ちます。同じ世界で、ほかのプレイヤーの会社と、乗客や土地を取り合います。

  • 勝ち負けは決まっていません。時価総額のランキングで競ったり、自分の街を育てたり、好きに遊べます。
  • 世界はみんなで共有しています。ほかのプレイヤーの路線・施設が、同じ地図の上に見えます。
  • セーブは要りません。サーバーが自動で保存します。ログアウトしても、会社は残ります。
  • ログアウトしている間、あなたの会社は止まります(車両も走らず、収入も費用も動きません)。誰もログインしていない間は、世界全体が止まります。
  • 時間の速さは、実時間 60分でゲーム内1日です(サーバーの設定で変わることがあります)。

2. はじめの10分

登録して入る

  1. トップの画面(https://rivalines.com/)で、言語を選びます(ブラウザの言語に合わせて自動で選ばれます)。
  2. 名前(2〜16文字)とパスワード(6文字以上)で「新規登録」します。メールアドレスや本名は要りません。名前はほかのプレイヤーに見えるので、本名は使わないでください。
  3. 「本稼働」(みんなが遊ぶ世界)を選びます。「次期バージョン」は、新しい機能を試すための世界で、データが消えることがあります。

はじめてのバス路線(いちばん簡単な遊び方)

最初の資金は ¥30,000,000 です。街の近くから始まります。まず、街の中の道路を使って、バスの路線を1本作りましょう。

  1. 道路を引く。上の道具から「🛣 道路 ▾ → 道路 (R)」を選び、街の外れから別の街・施設の近くまで、マップの上をドラッグします。街に元からある道路につなぐと、そのまま使えます。
  2. バス停を2つ置く。「🚏 バス停 (B)」で、道路の上を2か所クリックします(乗客が多い、建物の多い場所が向いています)。
  3. 車両基地を置く。「🏭 車両基地」で、道路の上をクリックします。
  4. 路線を作る。右の「路線」パネルで「＋🚌」を押し、バス停を順にクリックして、「確定 (Enter)」を押します。
  5. バスを買う。置いた車両基地をクリックして、車種と路線を選び、「購入」を押します(「路線」パネルの「＋車両」でも買えます)。
  6. 見守る。バスが走り出し、乗客が乗り降りします。上の現金が増えていけば成功です。収入は、画面の上に緑の「+」で浮かびます。
うまくいかないときは、「14. 困ったとき」を見てください。「バスが動かない」「乗客がいない」の多くは、バス停が道路から外れている、路線の停留所が2つ未満、車両基地が遠い、のどれかです。

次の一歩

  • バス停を増やして、路線を伸ばす(8分間隔などの時刻表も作れます → 6章)。
  • 鉄道・飛行機に広げる(5章・6章)。
  • 駅の近くにホテルや百貨店を建てて、乗客から売上を得る(8章)。
  • 経営画面で、借入や配当、研修などを使いこなす(9章)。

道路

  • 道路 (R):ドラッグして敷設します。高低差が1段までなら、スロープでつながります。
  • 一方通行 (O):ドラッグした方向にだけ通れる道路にします。双方向に戻す (T)で解除します。
  • 橋・トンネル (Y):両端をドラッグして、川や山を越えます。
  • バス停 (B):道路の上をクリックして置きます。
  • 車両基地:道路・直線の線路・空港の格納庫(またはターミナル)の上をクリックして置きます。車両を買う場所です。

線路と駅

  • 線路 (L):ドラッグして敷設します。約45度の角度でドラッグすると、斜めに敷けます。
  • 線路を自動敷設:始点から終点までドラッグすると、既存の線路を使い、障害物や高低差を避けて、最短でつなぎます。長い距離で便利です。
  • 駅 (K):番線数、ホームの長さ(タイル)、デザイン、向き(東西・南北)を選んで、クリックして置きます。クリックした位置が左上になり、範囲内の線路は自動で敷かれます。駅の外側の線路は、自分でつなぎます。デザインは、プレビューを見て選べます。
  • 経由点:直線の線路に置きます。路線に加えると、列車がその線路を通ります。使う番線や、待避の場所の指定にも使います。
  • 信号 (N)と信号を並べる:信号を置くと、列車が前の列車に近づきすぎないよう、線路を区間(閉塞)で区切ります。「信号を並べる」は、線路をドラッグして、一定の間隔で一方向の信号を並べます。
  • 橋・トンネル (H):線路の橋・トンネルです。
  • 車両基地(鉄道):直線の線路の上に置きます。

空港

「🛫 空港」は、大きさ(小・中・大・ハブ)とデザイン(1〜10)と向き(東西・南北)を選んで、平らな空き地に置きます(🎲 でランダム)。デザインは、ターミナルや格納庫や駐機場の並び方、滑走路の位置が違います。クリックした位置が空港の中心です。置く前に、レイアウトの図と、費用・滑走路の数・駐機場の数が出ます。

  • 空港は、滑走路・誘導路・駐機場・ターミナル・格納庫でできています。ターミナル(青いタイル)が停留所で、路線にはこれを使います。格納庫が車両基地の場所です。
  • 飛行機の路線は、空港をクリックして作ります。
  • 空港が小さいと、大きな機体は使えません。小さい空港は小型機だけ、中の空港は中型機まで、大きい空港とハブはすべての機体が使えます。
  • 平らでない場所には置けません。先に、地形の「整地」で平らにしてください。

飛行機の地上の動きと、着陸待ち

  • 飛行機は、格納庫から駐機場へ移り、そこで乗客を乗せます。出発するときは、誘導路を通って滑走路の端まで進み、滑走路で加速して離陸します。着陸したら、誘導路を通って、空いている駐機場へ進みます。
  • 滑走路は、同時に1機だけ使えます(離陸も着陸も)。同時に着陸することはできません。
  • 着陸しようとする飛行機が、滑走路や駐機場の空きを待つときは、空港の近くで円を描いて旋回しながら待機します。空いたら降りてきます。待つ飛行機が多いのは、空港が足りないという合図です。
  • 駐機場は、1か所に1機です。駐機場が全部埋まっていると、新しい飛行機は着陸できずに旋回します。
  • 大きい空港とハブは、滑走路が2本あるので、離陸と着陸を同時にさばけます。
  • 古い3×3の空港は、これまでの動き(端末から直線で飛ぶ)のままです。

地形

「⛰ 地形 ▾」で、地面を上げる (U)、下げる (J)、整地 (G)(最初にクリックしたタイルの高さに揃える)ができます。ドラッグした範囲が対象です。

撤去

  • 「🧹 撤去 (X)」で、ドラッグした範囲の中の、選んだ種類の要素だけを撤去します。道路・線路・信号・駅/停留所・車両基地・経由点・橋/トンネル・街の建物・空港から選びます(「すべての交通施設」「道路のみ」などのボタンもあります)。
  • 駅・停留所・経由点・車両基地・施設・空港を含むときは、実行する前に確認のウィンドウが出ます。最初に選ばれているのは「キャンセル」です。
  • 他社のものと、街の公共施設(市役所・学校・観光地)は、撤去できません。

6. 路線と車両

路線を作る

  1. 右の「路線」パネルで、＋🚌(バス)・＋🚆(鉄道)・＋✈(飛行機)のどれかを押します。
  2. 地図上の、同じ種類の停留所(バス停・駅・空港)を、通る順にクリックします。作成中にクリックしたところに、バス停(B)・駅(K)・空港(P)が置かれることもあります。
  3. 「確定 (Enter)」で決定します(取り消しは「キャンセル (Esc)」)。2つ以上の別の停留所が必要です。

路線は1人あたり300本までです。

オーダー(停車の条件)

路線の各停留所には、オーダーがあります。車両は、そのオーダーに従って停まり、出発します。

  • 間隔(停車):決めた秒数だけ停まって出発します。
  • 満載待ち:満員になるまで待ちます(最大の待ち時間つき)。
  • 時刻表:決めた時刻に出発します。1日の中の時刻と周期で決まります。
  • 通過:その駅には停まらず、通り抜けます(快速・特急)。
  • 条件付きジャンプ:積載率・待ち人数・時刻などの条件で、別のオーダーへ飛びます。
  • オーダーの並べ替え(▲▼)、挿入(＋)、削除(✕)ができます。

車両を買う

車両基地をクリックして、種別・車種・両数・配属する路線を選び、「購入」を押します。最寄りの基地から買う「＋車両」ボタンもあります。

種類車種の例ひと言
バスミニバス〜連節バス・二階建てバス安くて始めやすい。道路がある所ならどこでも。
電車単行・路面電車・ローカル・通勤・近郊・快速・特急・高速・地下鉄・観光1両ごとの価格で、編成の両数を選びます。運べる数も速さも大きい。
飛行機小型機・中型機・大型機高価ですが、長い距離を速く運べます。

車両は毎日、運行費がかかります(価格に比例。研修や国策で増減します)。車種は「型・名前・両数・定員・速度・価格」が一覧で見られます。

編成の操作(鉄道)

駅の近くに停まっている編成を、情報パネルから操作できます。

  • 分割:後ろから指定した両数を切り離します。切り離した編成は、待機します。
  • 連結:隣り合う2つの編成をつなぎます。
  • 出発:待機中の編成を出発させます。

ダイヤ(運行図表)

「📈 ダイヤ」では、時刻表をスジ図で見て、🚆 列車を動かす(その列車の発車時刻がずれる)か、🕒 駅の時刻を動かす(その駅の発車時刻が変わる)ドラッグで編集できます。待避の提案では、追い越しが起きる場所を見つけて、「適用」で、その待避を時刻表に入れられます。

車両の情報と追跡

車両をクリックすると、路線・状態(走行中・停車中・待機中)・積載・この先の停車駅が見られます。「📍 追跡」を押すと、カメラが車両を追いかけます。信号が赤で止まっているときは、その表示が出ます。

停留所の使用許可

他の会社の停留所は、持ち主の許可がないと、路線に使えません。自社の停留所の情報パネルで、「🔑 他社の利用を許可」から、会社ごと(または全駅)に許可できます。他社の線路・道路を通ったときは、通行料がかかります(11章)。

7. 乗客と街

乗客はどこから来る?

  • 乗客は、停留所の集客圏(まわりの建物・人口)から生まれます。人口が多く、建物が近い停留所ほど、乗客が多くなります。
  • 乗客は、行き先を決めて、その停留所で待ちます。乗りたい路線が来ると乗ります(待ち人数は、停留所に表示されます)。
  • 行き先まで、1本の路線で行けないときは、乗り換えをします。つながった路線網が大きいほど、行ける場所が増えます。
  • 運賃は、乗るときの基本運賃と、降りたときの距離運賃です。

街の成長

  • 街は、人口で「村 → 街 → 都市 → 特大都市 → 首都」と大きくなります。交通サービスがよい街は成長し、新しい建物が建ちます。
  • 建物は、工事中(2〜3日)を経て完成します。工事中の表示が出ます。
  • 街が大きくなると、民間の百貨店・ホテル・モールなどが建ち、それは売り出しや買収の対象になります。
  • 病院は、近くの街の成長を速めます。

沿線開発

天気・休日・イベント

日ごとに天気(晴れ・雨・雪など)が変わり、休日があります。施設ごとに、雨や雪や休日、季節で、来場者が増減します。コンサート・展示会などのイベントの日には、その施設の需要が数倍になります。

会社の評価

会社の評価は、運行範囲(人口カバー率)・待ち人数の少なさ・渋滞のなさ・定時性から決まる、運行の質の点数です(最初は65点)。「最悪」(15点未満)になると、新しい施設や路線を開発できなくなります(撤去・路線の編集・車両の購入はできます)。待ち人数や渋滞を減らして、25点以上に戻すと解除されます。評価は、信用(借入の条件)にも関わります。

14. 困ったとき(よくある質問)

バスが動かない・走り出さない

  • 路線に、異なる停留所が2つ以上入っていますか。
  • バス停は、道路の上に置かれていますか。道路が途中で切れていませんか。
  • 車両を買いましたか。路線だけでは、走りません。車両基地から買います。
  • 車両基地は、路線の停留所と道路でつながっていますか。
  • 現金が足りないと、買えません。経営画面で、借入ができます。

乗客がいない・収入がない

  • バス停のまわりに、建物(人口)がありますか。街の中や、街の近くに置きましょう。
  • 停留所をクリックして、「待ち」の人数を見ます。ゼロなら、集客圏に人がいません。
  • 運賃の倍率が高すぎると、乗客が減ります。
  • 経営分析の「路線別の採算」で、赤字の路線を探します。

列車が止まる・渋滞している

  • 線路が駅の外側で、つながっていますか(駅の外側の線路は、自分でつなぎます)。
  • 信号が赤で待っている場合があります。単線に車両を入れすぎないでください。待避の場所(経由点・待避線)を作ると、改善します。
  • 路線の車両が多すぎないかを見て、「−」で減らします。

「他社の停留所です」と出る

他の会社の停留所は、持ち主の許可がないと使えません。持ち主に頼んで、「他社の利用を許可」をしてもらいます。

「資金が足りません」と出る

経営画面で、借入ができます(格付けで上限が決まります)。会社の評価が「最悪」だと、新しい開発はできません。

施設を建てられない

  • 敷地に、建物・道路・線路・橋・空港・停留所・車両基地が重なっていませんか。
  • 立地の条件(スキー場=高地、ビーチ=海の近く、駅ビル=鉄道駅から4タイル以内)を満たしていますか。
  • ほかの会社が、その街でその種類の独占権を持っていませんか。
  • 会社の評価が「最悪」ではありませんか。

画面が古い・動作がおかしい

新しい版が出たときは、画面の上に「新しい版が出ました。再読み込みしてください」と出ます。ブラウザを再読み込みしてください。

世界が止まっている
